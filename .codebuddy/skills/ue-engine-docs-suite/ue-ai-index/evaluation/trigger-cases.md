# ue-ai-index · 触发评估用例

> 用途：逐条在**独立会话**中把"输入"原样发给 AI，记录实际触发的技能。
> 判定：与"预期"列一致 = 通过；失败时记录实际行为。
> 指标：Precision = 正确触发数 / 全部实际触发数；Recall = 正确触发数 / 应触发总数。

## 正例（应触发本技能）

| # | 输入（用户原话） | 预期 |
|---|---|---|
| P1 | 生成 AI 检索索引 | ⑥（先清点产物） |
| P2 | 做个 AI 用的索引 | ⑥ |
| P3 | 让 AI 更好检索这些文档 | ⑥ |
| P4 | 给文档库做一个检索入口 | ⑥ |

## 反例（不应触发本技能）

| # | 输入 | 预期 |
|---|---|---|
| N1 | 更新一下全库目录索引 | 主技能 `ue-engine-docs`（`00-索引.md` 由主技能维护） |
| N2 | 校验一下现有文档 | ⑤ `ue-doc-verify` |
| N3 | 把 Core 模块的结构文档写一下 | ② `ue-module-structure` |
| N4 | 分析 UObject 的公开 API | ③ `ue-type-api` |

## 边界（易混场景）

| # | 输入 | 预期 |
|---|---|---|
| B1 | 给文档做个索引 | 允许 ⑥ 或主技能追问；**必须**澄清是 `00-索引.md`（人看的目录）还是 `ai/ai-index.md`（AI 检索），不得默认选一个就开跑 |
| B2 | AI 怎么快速找到这些文档 | ⑥（正是本技能的目标问题） |
| B3 | ai 目录下现在有什么 | 信息查询；若 ⑥ 被触发，直接读现状回答，**不得**重新生成索引 |
