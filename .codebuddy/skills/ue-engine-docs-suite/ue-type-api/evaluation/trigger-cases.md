# ue-type-api · 触发评估用例

> 用途：逐条在**独立会话**中把"输入"原样发给 AI（不附加任何提示），把实际触发的技能填进"实际"列。
> 判定：逐条落"判定"列——`实际` 与 `预期` 一致 = `通过`；触发其他技能或未触发 = `失败`。**不要只记总数。**
> 指标：Precision = 正确触发数 / 全部实际触发数；Recall = 正确触发数 / 应触发总数。
> 重跑时机：本技能 `description` 变更后重跑本文件；步骤 / 示例变更后重跑 `quality-cases.md`（见 `使用说明.md` 第八节）。
> 域外反例 D1–D4 为**套件共用基线**（7 个技能用同一组），用于度量泛化误触发，便于横向比较。
